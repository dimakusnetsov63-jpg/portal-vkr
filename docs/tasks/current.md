## Как вести этот файл

1. Задача попадает сюда, когда над ней начали работать.
2. Крупная задача оформляется отдельным файлом по
   [`TEMPLATE.md`](TEMPLATE.md), здесь остаётся ссылка и статус.
3. Завершённая задача переносится в [`completed.md`](completed.md) с датой
   и хешем коммита — не удаляется.
