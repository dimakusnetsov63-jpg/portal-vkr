## TASK-008 — Раздел «Ставки»

**Статус:** `IN PROGRESS`
**ТЗ и детали:** [`TASK-008-rates.md`](TASK-008-rates.md)

Тарифы по проекту/городу/юр. лицу/должности: ставка за час/единицу/смену,
доход за смену/неделю/месяц (считается на клиенте, не хранится), зарплатный
проект, бонусы, акции, условия оформления. Реальные данные Supabase
(`public.rate_cards` + `public.rates`, связаны FK с каскадом), доступен всем
четырём ролям. Код, документация, миграции (применены к боевой БД) и
регенерация типов готовы.

Осталось:

- [ ] ручная проверка по [`../testing/checklist.md`](../testing/checklist.md)
      под всеми четырьмя ролями по отдельности — пройден один ручной прогон
      основного сценария (создание/правка/обновление страницы/удаление)

Не вошло в задачу и оставлено долгом:

- [ ] список проектов «Ставок» не синхронизирован со списком
      `candidate_project`, используемым остальными разделами
- [ ] истории изменений тарифа нет (ни построчной, ни снимка «кто/когда» в
      списке — только `created_by*`/`updated_by*` на самой строке)

## Как вести этот файл

1. Задача попадает сюда, когда над ней начали работать.
2. Крупная задача оформляется отдельным файлом по
   [`TEMPLATE.md`](TEMPLATE.md), здесь остаётся ссылка и статус.
3. Завершённая задача переносится в [`completed.md`](completed.md) с датой
   и хешем коммита — не удаляется.
